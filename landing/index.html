Local-First Architecture

Full Document Control.
Without Cloud Risk.

Online document tools upload sensitive contracts, invoices, and bank statements to remote servers. FileDeck executes OCR, full-text indexing, and AI synthesis strictly on your local CPU.

  • 100% Offline Privacy
    Files never leave your machine. No telemetry, third-party analytics, or cloud storage syncing.
  • Intelligent Document Processing (IDP)
    Extract structured tabular data from invoices and tax records with custom schemas, bounding-box review, and Excel (.xlsx) export.

    Rust-powered Tantivy search index locates text across millions of OCR tokens, titles, senders, and tags in milliseconds.

How does FileDeck process documents without the cloud?
FileDeck coordinates a Rust Axum backend with a local Python daemon running RapidOCR (ONNX runtime) and PyMuPDF. Text extraction, Tantivy indexing, and file conversions occur directly on your computer's CPU. No network socket opens outbound, and zero telemetry is collected.
Which AI model is used and does it require an NVIDIA GPU?
FileDeck uses the Qwen 2.5 (1.5B Instruct) model via quantized GGUF weights. It runs smoothly on standard multi-core desktop CPUs without requiring an expensive GPU or external cloud API keys.
Are there file size or document count limits?
No arbitrary software limits exist. FileDeck is constrained only by your physical hard drive space. The underlying SQLite database uses Write-Ahead Logging (WAL) for concurrent operations, and the Tantivy search index comfortably scales to hundreds of thousands of records.
How does IDP (Intelligent Document Processing) work?
You define custom extraction schemas for receipts, bank statements, or invoices with data types (currency, date, numeric, string) and regex validation rules. The system reads scanned files, maps text coordinates into a review grid, and lets you verify bounding boxes side-by-side before exporting to styled Excel (.xlsx) workbooks.
What happens if I accidentally delete a document?
FileDeck maintains an automatic 30-Day Safety Trash Bin. Soft-deleted documents remain recoverable for 30 days with one click, preserving version histories, tags, and notes before any permanent purge confirmation.
Is FileDeck open source?
Yes. FileDeck is released under the permissive MIT License. You can inspect the source code, run it completely offline in sensitive work environments, modify it, or build custom extensions without recurring subscription tiers.
